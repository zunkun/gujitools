## 方案讨论：非古籍 / detect 出错时「跳过检测、整页去底色」（未编码）

用户提出：处理的不是古籍 PDF，或古籍识别出错时，能否跳过 detect、整页去底色、直接打印。
只讨论可行性，未改代码。结论（读码所得，供后续实施）：

**管线事实**（关键，容易想错）：
- `functions/rembg.py` 是**整图 Otsu**，全文不读 boxes —— detect 的框与「去底色」无关。
- 框只在 ④ 起作用：`desktop/services/print_plan.plan_rembg_submit_entries` 派生
  box/parea → `entry_to_effect_spec` → `desktop/stages/rembg_stage.py:56-65`
  （`if effect and any(boxes)` 否则 `outputs=[image]` **整页原样交付**）。
- `runner.run_stage` 对 detect/rembg **无前置门控**，只要求页面清单非空。
  → **今天零改动就能：导入 → 跳过 detect → 生成预览 → 提交 → 打印。**

**但「整页」目前是「没框」的副作用，不是显式模式**，且有两个真陷阱：

1. ⚠️ **zoom=1 = 72DPI**（`utils/pdf_utils.calculate_zoom`，`core/command_spec` extract 默认
   zoom=1、quick=True）。古籍扫描件靠内嵌高清图走 quick 快路径；**矢量 PDF 无整页内嵌图 →
   必然降级整页渲染 → 72DPI 糊图**。这是「能不能用」的分水岭，改造要把「缩放因子」换成
   「输出 DPI」（300/72≈4.17），注意 `target_width>6000` 的上限钳制。
2. ⚠️ **对干净的矢量 PDF，二值化是负优化**：抗锯齿灰边被硬切 → 锯齿/断笔。
   type=3（灰度）温和；更稳的是按非白像素占比自动跳过（`rembg.py:115` 的 `non_white<500`
   分支已在此附近，可顺势扩展）。

**改造路线（成本递增）**：
- A 最小：area 加「0=整页」（command_spec + print_plan + rembg_panel + 预览不拆 -r/-l）
  + extract 改 DPI 语义。
- B 中等：加「文档模式」预设（跳过 detect / area=0 / 300DPI / type=3 / A4 竖版 / 关标题页码）。
- C 最大：PyMuPDF 直接 PDF→PDF 保持矢量，与现有图片管线不是一套，暂缓。

顺带发现：print.py:322 `text_margin=8mm` 是硬编码（给竖排标题/页码留白），
关闭标题与页码后仍留白，普通文档会被白白缩小 —— 可改为按需取 0。

## 已落地：area=4「整页/不检测」（用户拍板方案，已编码 + 自测）

用户方案：area=4 → 不调 YOLO，默认框 = 整页边界（跟图片一样大），用户可自己画；
rembg 按框去底色。比原「area=0/无框」更好：把「整页」从「没框的副作用」升级为
**显式可编辑的框**，下游 area/border 逻辑完全不用为空集特判。

**关键发现（省了大量改造）**：`build_output_layout` / `compose_region_output` /
`plan_rembg_submit_entries` 对「单框」的处理在 area=1 与非对称 area=2 下**结果一致**
（画布 = 框 + border，无 border 时整页写回）。所以 area=4 **不需要动几何层**，
只需：① 校验放行 4；② detect 侧不调 YOLO + 合成整页框；③ 派生层给 area=4 补分支。

改动清单：
- `core/command_spec.py`：`CROP_AREAS=(1,2,3,4)` + `WHOLE_PAGE_AREA=4`（新常量，跨层共用）。
- `functions/text_region.py`：YOLO 模型**改按需加载**（`_ensure_model()`，构造期不再加载）；
  `area_mode==4` 在调用检测之前分流，整页 `[0,0,w,h]` 作为唯一框。
- `desktop/components/panels/detect_panel.py`：新增「整页模式：不调用 YOLO」CheckBox
  + `whole_page_toggled` 信号 + `set_whole_page()`（blockSignals 回填，防回抛循环）。
- `desktop/components/panels/rembg_panel.py`：area 下拉加 `4 (整页/不检测)`。
- `desktop/pages/taskdetail/detect.py`：`_whole_page_entry()`（**只认 origin=manual**，
  auto 框在整页模式不生效，避免「选了整页却还是旧检测框」）、`_current_boxes_for()`、
  `_image_size_for()`（sizes.json → QImageReader 回退）；整页框**不入库不进缓存**
  （派生值，切回 area=1 不会被当成真实检测结果拆 -r/-l）。
- `desktop/stages/detect_stage.py`：area=4 时不加载 YOLO、不发 page_boxes
  （因此不写 boxes.json），只报进度 + 一条「跳过 YOLO」日志。
- `rembg_viewer` / `print_plan`：area=4 多框取并集、单条、parea=1（**不做对称镜像**）。
- 新自测 `tests/selftests/whole_page.py`（20 条，DEPENDS=[]）；`rembg.py` 加联动断言。
