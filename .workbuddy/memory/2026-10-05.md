## 关键设计

- **`FlowLayout` 是几何的唯一实现**（纯逻辑不 import Qt）：既是 `flow.bpmn` DI 段
  的数据源，也是 GUI 画布的换算依据。GUI 只做 `float → QPointF`。两份几何必然漂移。
- **默认模板是导出物**：`ports.SUPPLIERS` 仍是唯一真源，`gen_default_bpmn.py` 从它派生。
  自测断言逐字节一致 —— 忘了重生成当场红。
- **条件边永远绕行**：`imposition → print`（`guji:condition="imposition"`）即便与主路径
  同行也绕行绘制，否则虚线被实线主路径完全盖住。
- **落点纵向错开**：多条边进同一节点按 `(landing - (total-1)/2) * LANDING_GAP` 居中均分，
  否则重合等于只画一条。
- **两下标并存**（本轮最大的坑，见下）。

## 三套下标（本轮踩得最重）

BPM 驱动后步骤条格序含可选节点占位，**格序 ≠ 栈页号**：

```
格序 bar_index :  extract=0 detect=1 rembg=2 imposition=3 print=4
栈页号 stack   :  extract=0 detect=1 rembg=2 print=3     imposition=4
```

`_select_stage()` 收**格序**，`control_stack.currentIndex()` 是**栈页号**。
`IMPOSITION_INDEX = len(STAGES) = 4` 是改造前的遗留口径，现在落在 **print** 那一格。
全仓 18 处写死下标已改成 `bar_index_of_step(step)` / `stack_index_of_step(step)`。
旧硬编码 0/1/2 恰好在可选节点之前才没受影响 —— `3` 一律错。

## Qt 尺寸/绘制坑（本轮）

  正解：`setSizePolicy(Min,Fixed)` + `setMinimumSize(1,1)` + `setMaximumSize(w,h)`
  + 重写 `sizeHint`/`minimumSizeHint`。
- `QScrollArea.setWidgetResizable(True)` 会按视口高度拉伸内层控件 ⇒「内容多大就多大」

## 本轮修的 bug（都是自测抓不到的）

1. ⚠⚠**qfluentwidgets `Dialog` 放不下流程面板**：`Dialog(title, content: str,
   parent)` 第二参是字符串、**没有** `viewLayout()`/`cancelButton`（它其实是
   MessageBox）。**三个弹窗同时踩中**，且自测全都直接实例化 `*Panel` 从不构造
   外壳 ⇒「创建任务」点开就炸但 306 项断言全绿。
   新增 `desktop/components/dialog_shell.py::shell_dialog`（QDialog + 自搭标题与
   按钮）统一接管；`flow_ui` 加了一组「弹窗外壳能构造（parent 非 None）」钉子。
2. ⚠**面板 `self.close()` 关不掉弹窗**（面板自己没窗口）⇒`self.window().close()`。
3. ⚠`FlowEditorPanel._refresh_status` 调不存在的 `canvas.selected()`
   （真名 `selected_node()`）——只有**无参构造**该面板才走到，自测都从已有
   流程构造，掩盖了它。
4. ⚠`FlowEditorPanel._build_ui(flow, layout)` 的参数名与局部
   `layout = QVBoxLayout(self)` 同名，传入的节点坐标被顶掉（报
   `'QVBoxLayout' object has no attribute 'boxes'`）⇒改名 `initial_layout`。
5. ⚠`FlowView` 构造期不能事后 `set_flow(flow, layout)` 补坐标（进布局后 Qt 反复
   问 sizeHint，时序不可控）⇒坐标必须在**构造时**给（新增 `layout=` 参数）。
6. ⚠`FlowView._wrap_width()` 用 `self.viewport()` 永远返回 0（自己就是滚动区的
   `setWidget` 内容、没有 viewport）⇒ 折行永不触发。改问**父容器**的 viewport。
7. ⚠折行后必须**显式 `resize`**：`setWidgetResizable(False)` 的滚动区不会替我们
   收控件尺寸，父布局也只按 sizeHint 分配空间、不改子控件已有几何 ⇒「折行了但
   看着还是一行」。
8. ⚠流程图**垂直居中**（`AlignVCenter`）而非顶对齐：画布仅~144 高、视口 400+，
   顶对齐会把空白全堆在图下方（看着像"图没画完"）。
9. ⚠`content_size` 宽度要**两侧都算**：折行居中后节点整体右移，只取
   `max(x+w)` 会漏掉左侧留白。
10. ⚠判"要不要按新宽度重排"用 `_auto_width`（哨兵 `AUTO_WIDTH_PENDING=-1`
    表示"自动但还没绑宽度"），**不要**用 `_user_moved`：外部
    `set_flow_layout` 不置它，会被静默重排回去（"拖动节点：坐标变了"假红）。
11. ⚠PySide6 **不导出** `QWIDGETSIZE_MAX` ⇒ 用 `(1<<24)-1`。
12. ⚠流程阶段中文名三处自取（`flow_view.stage_title` /
    `flow_editor_panel.stage_display` / 旧 `to_xml`）绕过 `ports.stage_label()`
    ⇒`rembg_submit` 与 `rembg` 同名，流程图出现**两个「图片去底色」**。全部改走
    `stage_label`，加 3 条守卫断言。

# 第三轮：bpmn 文件成为唯一真源（架构掉头）

## 用户三条硬要求

> 1. 页面渲染 bpmn 流程图，**按照页面定义的渲染**
> 2. 页面**可以编辑**
> 3. **后端驱动可以用状态机**，bpm 流程引擎太复杂

## 之前的根本性错误（必须记住）

**方向反了**：`ports.SUPPLIERS`（端口级边表）是"代码事实"，`flow.bpmn` 只是
它的**导出物**；页面渲染走 `FlowView`，**坐标自己算**、只有矩形/圆两种图形。
⇒ 用户在 bpmn.io 画好带网关的图，进页面看到的是**另一张图**（无网关、坐标
不同）。且 `FlowDefinition.load()` **不支持 `exclusiveGateway`**，读 bpmn.io
的文件直接抛 `ValueError: 未知阶段 'Activity_05a13ao'`。

**新方向**：`flow.bpmn` 是**唯一真源**。

```
                    ┌── 渲染/编辑 ──> bpmn_view.BpmnView / bpmn_editor.BpmnEditor
flow.bpmn ──读──> FlowDiagram
（唯一真源）     (节点类型+DI坐标+折点+边标签)
                    └── 运行顺序 ──> scheduler.Scheduler（状态机）
```

## 新增 4 个模块

| 模块 | 职责 |

| `desktop/components/bpmn_view.py` | `BpmnView`：照文件渲染（网关菱形、结束事件双圈、走文件折点） |
| `desktop/components/bpmn_editor.py` | `BpmnEditor(BpmnView)`：拖拽/连线/增删/改名，落盘即写 `.bpmn` |
| `desktop/steps/scheduler.py` | `Scheduler`：**状态机**（顺序取拓扑序、跳过看 `CONDITIONS`） |

**删除**（已无生产调用与自测引用，备份 `/tmp/bpm_backup/`）：
`flow_view.py` / `flow_editor.py` / `flow_editor_panel.py`。

## 这一轮真正的 bug（用户报"改了 task_default 程序没跟着变"）

⚠️⚠️ **栈页号 `stack_index` 是按"数当前有几格"算的，而两个栈是按静态步骤表
一次建好固定页数**。文件里少一步（用户当时那份不含「图片去底色」），后面每步
的页号整体前移 ⇒ 点「PDF排版」翻到「图片去底色」那一页。

修法：`FlowDiagram.stage_slots()` 里 `stack_index` 改成**查静态顺序表**
（`FLOW_STAGES + OPTIONAL_STEPS` 里的位置），不再用文件槽位序号。

**判定"在不在流程里"也要按界面格、不能按节点**：`rembg_submit`（提交去底色
结果）折在「图片去底色」那一格里，用户画图时不会给它单独开节点。按节点判会
认为它不在流程里 ⇒ `print.pages` 回退到 `rembg` ⇒ 拿到
`stages/rembgpreview`（**实时预览**目录）而不是 `stages/rembg`（**提交成品**）

## ① 「是否拼版」判据换源（`area` → 流程图）

**根因**：拼版节点在步骤条上出不出现，判据是**第三步的 `area == 1`**。而
`area=1` 的真实语义是「每个框各自外扩 border，产出多张图」＝**裁剪方式**，
跟拼版毫无关系。两重危害：

- **语义错配**：用户选了"左右分开"就凭空冒出拼版节点；
- **与用户的图打架**：图上把「图片拼板」删了、`area` 还是 1，那一格照样冒出来。

改法：`_imposition_node_visible()` 直接复用 `bar_index_of_step(IMPOSITION_STAGE)`
（与步骤条、`store.task_slots()` **必然同源**）。删掉 `_rembg_area_value` /
`_as_area` / `IMPOSITION_AREA`（查过只服务这一个判据）。

配套：拼版面板的「在流程中启用图片拼版」开关在**图里没这一格**时**置灰 + 说明**，
因为"勾了也不生效"（`stage_supplier` 会自动回退到去底色产物）。

## ② 「流程节点不能完全映射到 bpm 流程」——逐层量出来的缺口

写了个诊断脚本，对**三张图**（默认 / 少一步 / 多一步）分别量每一层的输出，
缺口一目了然（改前**三张图的任务列表胶囊完全一样**，都是硬编码的四个）：

2. ⚠️ **Signal 必须声明在 QWidget 子类里**（Mixin 里写 `Signal(...)` 不注册
   元数据、发不出去）⇒ `flow_edit_requested` 放在 `page.py::TaskDetailPage`。
3. ⚠️⚠️ **判"是否在编辑态"用 `isHidden()`，且方向别反**。我先写 `isVisible()`
   （祖先不可见时恒 False ⇒ 改名被静默丢掉），改成 `isHidden()` 后又写成
   `if not isHidden(): return`（= "可见才 return"，改名永远不生效）。
   正解：`if self.rename_edit.isHidden(): return`。
   `super().eventFilter(...)` 在 Mixin 里也不能调（对象没这个方法）⇒ `return False`。
4. ⚠️ `QKeyEvent` 在 **QtGui**（QtCore 里只有 `QEvent` 枚举与 `Qt`）——
   从 QtCore import 会 ImportError，自测一跑就炸。
5. ⚠️ `FIF.LEFT` 不存在；返回按钮用 `FIF.RETURN`（与详情页一致）。
6. ⚠️ `CreateTaskPanel` 早已改成"恒定显示当前流程"，**没有 `content_stack`**；
   内嵌编辑要显隐的是 `flow_title`/`flow_scroll`/`flow_summary`/两个按钮这一组。
7. ⚠️ 弹窗外壳里那段"遍历子控件找『取消』按钮"的脏办法（`del panel_cancel`）
   一并换成 `self.panel.cancel_button`。

### 补：流程编辑页的保存按钮放**顶部**（实测截图发现）

`FlowPanel` 自带的按钮行排在**最底部**，而独立页里画布很高 ⇒ 屏幕不够高时
「保存流程」**看不到，等于没法保存**。给 `FlowPanel` 加 `show_buttons=False`，
由 `TaskFlowPage` 在**顶部工具栏**放「保存流程 / 关闭」。

⚠️ 顶部按钮**直接**取 `panel.editor_panel.editor().diagram()`，不走
`panel.result_diagram()`——后者只在点过面板自己的「保存」后才非 None，
而本页把那个按钮收走了。
