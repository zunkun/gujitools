## 定案与实现：去底色那一步，必须提交才能传给下一步

用户口径：**去底色那一步的编辑，必须提交才能传给下一步**（第 3 条消息）。据此把
第四步从"拿去底图现算"改成"只排版提交产物"。

**改前实测**（`tests/probe_preview_submit_gate.py`，现在应全绿）：提交一次 → 编辑
`stages/rembgpreview`（不再提交）→ 第四步合成输入仍是 `#cc0000`（编辑漏进 PDF），
与日志里"点提交后才会用上"相反。根因：非拼版模式下 `plan_print_effects` 命中 label
时取的是"当前派生集合"（源 = 去底图），条目图被丢弃；这套现算同时是"改 border 免重提交"
的实现方式（`runner.py` 注释 + `print_area_border_e2e` 守着）。

**实现（选定：提交产物为唯一来源）**

- `submit._build_print_effects(list_entries)`：**签名去掉 area/border**，只
  `[{"file", "effect": None}]` 整图透传（拼版与非拼版同一条规则，`imposition_active` 判断
  不再需要）。
- 删除 `print_plan.plan_print_effects` + `_base_label`（连同"按基础页名对齐派生集合"那套
  逻辑——它正是"改过 area 后删掉的页复活"事故的来源）。
- `submit._preview_edited_after_submit()`：`rembgpreview` 里 mtime > 最近一次提交
  `finished_at` ⇒ 视为编辑过，`_rembg_submit_version_state()` 返回 `new_version`，
  按钮改口"有待提交"（否则编辑完按钮还绿着说"已是最新版本"，是假话）；
  `manifest._log_edit_downstream` 编辑后立刻刷一次按钮状态。
- 注释/文案同步：`runner.py`（print 分支改为"不重新合成"、日志行改为

### 算法：均值坐标 MVC（Floater 2003），**不是** GIMP 的 Green Coordinates

**为什么换**：Green Coordinates 要建 Green 函数做边界积分，实现重、数值敏感；MVC 有闭式解
`w_i = (tan(α_{i-1}/2)+tan(α_i/2))/|p_i-p|`，其中 `tan(α/2)=cross/(|d_i||d_{i+1}|+dot)`；
用户能感知的**形状保持 / 线性精度 / 朝向无关**都在，代价约 60 行 numpy。

三个**必须处理**的退化点（都真踩到过）：
1. 点落在笼边上 → `α→π`、`tan(α/2)→∞`：`denom<1e-9` 时按 `cross` 符号取 `±1e12`。
2. 像素**正好在节点上** → `|d|→0` 除零，用 one-hot 覆盖。
3. **笼只取周长采样**，绝不把笼内网点也放进点集——否则多边形自交、角度项算错。

## 变换笼：用户回报 3 个 bug + 2 个新需求（同日第二轮）

### 三个 bug 的**探针实锤**（都不靠猜）

- **变黑 = alpha 被丢掉**：`qimage_to_rgb` 只取 `[2,1,0]`、`rgb_to_qimage` 又强写 `alpha=255`，
  而流程产物是**白底透明 PNG**（透明处 RGB=0）→ 整片背景变**不透明黑**。
  探针：4096/4320 透明像素 → 4040/4320 纯黑。修法：`qimage_to_rgba`（`[:,:,[2,1,0,3]]`）+
  `array_to_qimage`（按 3/4 通道分别处理）+ 透明图越界填 `FILL_CLEAR=(255,255,255,0)`。
- **只能向内**：`cage_move_node` 夹在 `image_rect()`，而默认笼贴图边 → 外拖是空操作。
  修法：允许外拖，只留「一张图那么远」的宽松上限。
- **「折线」不是笼画成折线，是全局 MVC 把整笼带歪**：拖一个角整个页面歪成平行四边形。
  探针 `probe_locality.py` / `probe_rbf.py` 对比后改成**紧支撑 RBF 位移场**（Wendland C²，
  `φ(r)=(1−r)⁴(4r+1)`，`|φ'|max=135/64`），`s(p)=p+Σⱼwⱼφ(|p−mⱼ|/R)`，只把**动过的把手**当约束。
  自带「惰性」性质：`|p−mⱼ| ≥ R ⇒ s(p)=p`（**逐字节**相同）——恰好就是用户要的"尽量少影响远处节点"。
  顺带把 `cage_warp` 自测从 3.2s 压到 **0.4s**（只算影响盘并集，不再全幅）。
