### ⚠️⚠️ 子代理把 `manifest.py` 写成了乱码（已修）

修复函数（latin-1 → UTF-8 回环，按 0x80–0xFF 连续段批量解）：
```python
def repair(text):
    out, buf = [], []
    def flush():
        if not buf: return
        b = bytes(ord(c) & 0xFF for c in buf)
        try: out.append(b.decode("utf-8"))
        except UnicodeDecodeError: out.append("".join(buf))
        buf.clear()
    for ch in text:
        if 0x80 <= ord(ch) <= 0xFF: buf.append(ch)
        else: flush(); out.append(ch)
    flush(); return "".join(out)
```

所以 `install()` 写 `TMPDIR`（Python/子进程 Python 都认）+ `TEMP`/`TMP`（兜原生库）。
实测子进程 `python -c "import tempfile;print(tempfile.gettempdir())"` →
`D:\workspace\gujitools\tests\tmp` ✅。

⚠️ **`install()` 必须早于任何 `tempfile` 调用**：`gettempdir()` 第一次算完就把
结果缓存进 `tempfile.tempdir`，之后再改环境变量不生效。
