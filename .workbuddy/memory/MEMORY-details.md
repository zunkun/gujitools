- ⚠⚠**统一变换＝`geometry.compose_transform` 一条数学**（预览与烘焙共用）。⚠**绝不用 `QPainter.setTransform(xf)`＋`drawImage(rect,region)`**：实测**不等价于 `map(rect)`**（漂 ~10px）且只支持仿射。像素一律走 `warp_placement`（取不到 numpy 才退 QPainter）。⚠返回值多形态（`grow=False`=QImage、`True`=(图,原点)）⇒ 一律 `r[0] if grow else r`。
- ⚠⚠⚠**病态投影的尺寸闸门＝`geometry.mapped_bounds()` 是唯一判据**（2026-10-09 真实崩溃：用户把透视角拖到对角附近 ⇒ `quad_to_quad_transform` 给出 m33≈1e-6 级矩阵 ⇒ `warp_region` 已被 40MP 闸门拒绝，但 `warp_placement` 的 **QPainter 兜底没挡**，`QImage(2.18e9, 1.49e9)` 直接 OverflowError；`compose_transform(grow=True)` 同病）。判据三选一即 `None`＝**宁可不画**：①角点坐标非有限（w→0 甩到 ±inf）②坐标绝对值 > `ABSURD_COORD`(1e8，近共线投影实测到 1e9) ③外框像素数 > `WARP_MAX_PIXELS`(40MP)。**四个入口全部走它，别在各处另写 min/max**：`warp_region`（返回 None）、`warp_placement` 兜底（返回 `(QImage(), 0, 0)`＝空图不画）、`compose_transform(grow=True)`（退回原图边界）、`transform.py` 透视步进（`transform_perspective` 与拖拽 `_xf_persp` 都先 `mapped_bounds(xf*step)` 探路，None ⇒ **整步拒绝、框保持原样**——比"夹到最小 0.05"安全：病态矩阵夹完还是病态）。探针：极端切变 k=1e4（外框 3.6e9 px）、m33=1e-9（5e17 px）都被拒且不崩、正常透视仍可用。
- ⚠⚠**变换预览＝两档，图元矩阵口径故意不同**（2026-10-09 修"只旋转不能实时"）：**拖动中**（`_xf_dragging`）＝快档：像素**不重采样**（画布＝`_xf_preview_region`），变换全交给图元 `_float_fast_xf()`＝`S(1/k)*_placed_xf()`，**实测 0.6–2 ms/帧**（逐像素档 12MP 要 158/442 ms、k=1 的小图也 158ms ⇒ 就是"不能实时"）。**首次/松手后**＝精确档：`_render_float_plane()` 逐像素 `warp_placement(S(1/k)*placed*S(k))`，图元只 `_float_placement()`＝**纯 scale(1/k)+translate**（**m12/m21 恒 0**）。⚠**两档绝不可混用**（混＝内容转两遍或原地不动）；⚠`_apply_float_fast()` 末尾**必须清 `_xf_preview_keyframe`**（否则松手不补精确帧⇒跳变）。⚠摆位矩阵只一处定义＝`_placed_xf()`＝`translate(选区左上角)*_preview_xf(_xf)`（`_preview_xf` 管「校正（向后）」取逆）。
- ⚠⚠⚠**Qt 的 `A*B` 是"先 A 后 B"**（行向量约定；`(A*B).map(p) == B.map(A.map(p))`）——而 `S(k) ∘ placed ∘ S(1/k)` 这种**数学记号是先右后左**。旧版按记号直译成 `QTransform().scale(k,k) * placed * scale(1/k,1/k)` ⇒ 实际算的是 `placed(k·u)/k`，**平移量被多除一个 k**：k=0.6 时 160px 的位移能让内容偏出 920px（用户 2026-10-09 第三轮报障「图片边框那些操作框跟图片分离了、格子区域块跟图片相互远离」）。同一处错误还有 `_float_fast_xf`（旧 `placed*scale(1/k)`）。**修法（三处必须一起）**：`_preview_placement_xf`＝`S(1/k)*placed*S(k)`、`_float_fast_xf`＝`S(1/k)*placed`、`_render_float_plane` 里 `_xf_preview_origin` 要 **`(x0/k, y0/k)`**（`warp_placement` 回来的 `(x0,y0)` 在预览尺度里，而 `_float_placement`/`_cut_plane` 的口径是图片坐标）。

- ⚠⚠**撤销＝带名字的步骤时间轴**（`dialog_undo.py`）：`_undo`(变更前快照)＋`_redo`＋`_labels`，不变量 **`len(_labels)==len(_undo)+len(_redo)`**；`_labels[i]`＝"改掉 `_undo[i]` 这一步"的名字；节点 0＝`_origin_label`。⚠**只动 `_undo`/`_redo` 不动 `_labels` 历史会点错格**。跳转＝连按 undo/redo + **"推不动就停"兜底**；`_history_syncing` 是 `currentRowChanged` 闸门。
- ⚠️⚠**扭曲笔刷＝位移场累积＋区域重采样**（`image_editor/distortion.py`）：①`StrokeSampler._carry`**必须 `carry = length-(needed-step)`**，不许 `+= max(0,…)`（累加⇒"拖越久越卡"）；②预览按**精确脏矩形**、单帧受 `DISTORT_PREVIEW_RENDER_PIXELS` 约束、超出**挂回**下一帧；③提交只渲染 `field.active_rect`、与拖动时长解耦，>4 Mpx 走后台。
- `ImageViewerWidget` 两形态：图片(`set_images`/`set_thumb_source`)／PDF 页(`set_pdf_source`+`begin_pdf_pages`+`set_pdf_thumb`)；⚠`set_images` 须先 `_clear_page_source()`；`gen` 代际号防串页。print 页：未生成＝源图缩略、生成后＝产物页缩略。`RembgPreviewWidget.set_images(paths, rembg_dir)` **第二参是结果目录**。
- **编辑生效链**：`ZoomPopupMixin`→`ImageEditorDialog(save_back=True)`→`overwrite_image_file`→`image_saved`；独立页由 `ThumbSourceMixin._wire_source_edit()` 接（`_reload_edited_thumb` 要**先 pop `_thumb_cache_ready[path]` 再 `refresh_page`）；拼图页产物 `singletask/拼图/edited/<页>.png`。⚠⚠**回写后"界面没变"＝典型静默失败**，三因：①内存缩略图按路径缓存不过期；②**拿路径串直接 `==` 比**（Win 上 `/`→`\` 落空后整段 return）⇒统一走 `services/imposition.py::same_path/page_has_file`；③缓存失效只 pop 原样串（要扫**同形键**）。
- **「完成」覆盖确认**：`_confirm_overwrite()` 在任何烘焙前问；⚠`_finishing` 须先于确认框置位。四个短路 `return True`：`not save_back`/`not target_exists`/`_image==_original`/`MessageBox` 抛异常。⚠`editor.target_name` **只能做属性**；**给会替身化的函数加参数前先 grep 替身签名**。落地口径：独立任务页「应用」**一律落地实体文件**；任务流程**看目标**（有 `ZoomTarget.edit_path` 才落地）。

- ⚠只有 `task` 节点映射运行阶段（`endEvent` 常叫「生成PDF」，按名查表会误认成 `print`）；阶段按**节点名**接回（`STAGE_ALIASES`）。⚠⚠**端口依赖 ≠ 流程连线**（`(consumer,port)→supplier`＝取谁的文件；`sequenceFlow`＝先做哪一步）。状态机：`store.task_scheduler(tid,imposition_active)`（唯一查询面）／`store.stage_supplier()`／`stale_chain.upstream_from_diagram()`／`runner` 守卫（不在流程里的阶段直接拒）。⚠每层界面都必须问图：步骤条格子与**任务列表子任务胶囊**＝`task_slots`（**别写死 `for stage in STAGES`**）。

## 下标与步骤条（三套，别混）
- ①**格序 `bar_index`**（含可选节点占位）＝步骤条唯一语义（`StepItem.index`/`set_step_status`/`mark_completed`/`set_current`/`current_changed`/`imposition_index` 全是它；宿主传 `bar_indices=`＋`optional_bar_index=`；⚠徽标数字**仍按真实步骤序**）②**栈页号 `stack_index`** ③`control_stack.currentIndex()`。`_select_stage()` 收**格序**。
- ⚠⚠**`stack_index` 必须"查静态表"不能"数当前几格"**：两栈按 `FLOW_STAGES + OPTIONAL_STEPS` **一次建好固定页数**；正确＝`FlowDiagram.stage_slots()` 里的静态位置。**生产与自测都不许写死下标**（`bar_index_of_step()`/`stack_index_of_step()`/`panel_host_of_step()`）。⚠⚠**`_refresh_preview(index)` 入参是「栈页号」**⇒`_select_stage` 传 `self.stack_index_of(index)`；`runner.py` 两处 `_refresh_preview(1)/(3)` 改 `stack_index_of_step(...)`；`_refresh_downstream_preview(step)` 管"改完上游顺手刷下游"。
- ⚠重建步骤条/槽位时**"旧下标"必须用"旧快照"解析**（`_build_step_bar` 存 `self._step_bar_slots`）。⚠`set_task` 走 `_rebuild_step_bar` **重建整条**⇒自测跨 `set_task` 缓存的 `step_bar.imposition_node` 是**已析构控件**。⚠⚠⚠`task_diagram`/`flow_slots()` **都无缓存**（每次读盘）——"改了没反应"**别往缓存上查**。[测:flow_ui§14]
- ⚠⚠**取"别的步骤的面板"只有 `panel_host_of_step(step)` 一个入口**（`control_stack.widget(2)` 恒是「图片去底色」靠**静态步骤表顺序**）；返 `None` 时调用方自己降级。
- ⚠⚠**「是否拼版」＝三判据**：①在流程里②有意义＝`area==1`③面板底部开关（`imposition_active`＝**用户意图**）。全过＝`imposition_effective()`；取图来源/状态机跳过/步骤条生效态**一律认 effective**。⚠**`area` 是适用前提不是"显示开关"**：`area=1` 产出**成对** `-l`/`-r`；处置是**置灰+说明**不是隐藏，且**置灰时保留并回填勾选**。⚠⚠**界面与执行必须同一判据**。
- ⚠⚠**图上"画了但还没功能"的节点不许静默丢**：占一格＋`StageSlot.mapped=False`＋`stack_index=NO_PAGE(-1)`，画灰节点、副标题「未接入」，`_select_stage` 在 `set_current` **之前**拦下提示。⚠**`stage_states` 键只能加不能删**（调用方硬索引 `["rembg"]`）⇒留四静态键＋`in_flow` 标记，"只列流程里的"走 `flow_stages()`。⚠**沿图回退取产物要 `fold_forward` 折叠到同格最靠后的动作**。

- ⚠⚠**左侧列表缩略图"逐张到齐"回填不许整列重灌**（380页×380≈7.2万次 `set_thumb`、主线程 27.5s）：只贴刚到那条（`ImpositionViewWidget.set_thumb_at`）；`ImpositionPageList.set_thumb` 加"同一张早退"（`QPixmap.cacheKey()`）。

## Qt/界面通用坑
- ⚠⚠**Qt `clicked` 会顺手喂一个 `checked: bool`**：槽**只要带一个可选位置参数**就中招（`fit_btn.clicked.connect(canvas.fit)` ⇒ `fit(ratio=False)`、图缩成 1/4）。**接线一律套 lambda**，被调方对 `bool`/非数**降落回默认**。
- ⚠⚠**qfluentwidgets `Dialog` 放不下成套面板**（第二参是**字符串**、**没有** `viewLayout()`）⇒走 `components/dialog_shell.py::shell_dialog`。⚠**"点按钮就炸、自测却全绿"先怀疑外壳**（自测都直接实例化 `*Panel`）。⚠**面板 `self.close()` 关不掉弹窗**⇒用 `self.window().close()`。
- ⚠**编辑器必须有工具栏**（无按钮调用的动作＝死代码）；画布要有**尺寸下限**。⚠`NodePalette` 置灰项光靠 `ItemIsEnabled` **看不出区别**，须 `setForeground(INK_DISABLED)`。⚠**自定义初值缺失会静默回落默认**。
- ⚠`Card`（`ui/widgets.py`）**自带 layout、暴露为 `card.box`**——再建第二个 `QVBoxLayout(card)` 会被忽略、控件**留不下**（卡片空成 32×32）；卡片高度**用 `heightForWidth`**。
- ⚠界面：控件 `paintEvent` 自绘不引样式表；下拉 `widgets.combo_box()`；窗口尺寸 `ui/window_size.apply_window_size`。PySide6 **不导出** `QWIDGETSIZE_MAX`，用 `(1<<24)-1`。⚠高分屏绝不手 `painter.scale(dpr,dpr)`。⚠「点空白处」**直接**开选文件对话框；⚠**"资源管理器"＝原生 `QFileDialog`**（**不设** `DontUseNativeDialog`）。
- ⚠`SourceZone` 内有真按钮子控件：几何靠 `_relayout_buttons()`；`accepts_dir=False` 不摆目录按钮；**入口是主路径必须画成按钮**；`_open_dialog` 须 try/except 转 `rejected`。
- ⚠跨线程用 `desktop.workers.connect_queued`。⚠**`QThread.run()` 必须 try/except**（异常逃出不杀进程、`result=None` 被上层当"用户取消"）。
- ⚠GUI 主进程不许进重依赖(`functions.detect`→cv2)：主进程用的纯规则放 utils 且不 import functions（`box_geometry` 有 AST 守卫）。中文路径勿直用 `cv2.imread/imwrite`，走 `utils.image_io`。⚠按页号命名的缓存不能跨书共用。
- ⚠"重跑同一个源"不是"冲突"：收录尾"已存在就跳过"须先 `filecmp.cmp(shallow=False)` 比内容。⚠自测勿手写 JPEG/PNG 十六进制。⚠**传路径的公开 API 须在边界 `Path()` 收口**。⚠**同一输出目录只准一个写入者**（`stages/imposition` 靠 `_COMPOSE_LOCK`+`_save_page_atomic`）。⚠自我续期的 `QTimer.singleShot(0)`＝CPU 风暴：分批解码带间隔（`picker.THUMB_GAP_MS=150`）。
