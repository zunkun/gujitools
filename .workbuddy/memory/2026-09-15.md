# 2026-09-15 工作日志（gujitools）

## 界面：执行日志改为「底部状态条 + 点击唤出浮层」

用户反馈「日志输出子弹窗不好看，有什么地方可以摆放或者可以点击调用出来显示的」。
说明清楚：并没有独立弹窗，指的是任务详情页底部那条常驻的「执行日志」卡片
（`LogPanel`，收起 44px / 展开 212px，空闲时是一块空白卡占位）。

先画了三个候选方案（底栏状态条 + 点击弹出 / 右下悬浮按钮 / 并进右侧控制列）供选择，
用户选 **方案 A**。

### 改动
- 重写 `desktop/components/log_panel.py`：
  - `LogPanel` 从 `Card` 改为普通 `QWidget`，固定高 34px 的**状态条**：不画卡片底，
    只在 `paintEvent` 画一条 1px 上分隔线 + 左侧状态圆点；右侧是「清空」与
    「展开/收起」两个 26px 按钮；整条可点（PointingHandCursor）切换浮层。
  - 新增 `_LogOverlay(Card)`：浮层，白底 + `BORDER_STRONG` 描边 + `RADIUS_LG`，
    内含标题行（含关闭按钮）、`Divider`、以及共享的 `log_view`（等宽字体）。
  - 浮层是**状态条父控件（详情页）的子控件**，首次展开时才 `setParent` 挂上去
    （`__init__` 里先无父创建，好让 `log_view` 在页面组装阶段就可用），
    定位到状态条正上方、宽度与状态条对齐、高度 `min(260, 上方可用空间)`。
    挂在页面而非窗口 → 只在详情页范围内覆盖，且随状态条 `resizeEvent`/`moveEvent` 重排。
  - Esc / 点击浮层与状态条之外的任意位置关闭：展开时给 `QApplication` 装 eventFilter，
    收起时卸载。
  - 状态圆点三态：无输出 `INK_DISABLED`、有输出 `ACCENT`、最后一行含错误关键字 `DANGER`；
    摘要行颜色同步（出错红）。保留 `set_expanded(bool)` / `toggle()`，`runner.py`
    的「执行时自动展开」调用点不变；`log_view` 属性名不变，页面各处的
    `self.log_view.append(...)` 一行都不用改。
- `desktop/ui/theme.py`：新增令牌 `BORDER_STRONG = "#C9D1D8"`（浮层/悬浮面板描边）。
- `tests/gui_shot.py`：文件名改为与 `docs/gui/screenshots/` 一致的中文名（省掉手工改名），
  并新增第 6 张 `06-详情页-日志浮层.png`（展开浮层的状态）。

### 踩坑：全局 QSS 里的 `#logView` 其实一直没生效
浮层和预览卡片都是白的，边界糊在一起；想给日志域加浅底时发现**写在 `style.py`
全局 QSS 里的 `QTextEdit#logView` 规则根本不生效**（底色始终纯白、描边也没有）。
原因：qfluentwidgets 的 `TextEdit.__init__` 会 `FluentStyleSheet.LINE_EDIT.apply(self)`，
**给控件自身设一份样式表；控件级样式表优先级高于应用级**，所以全局规则被盖掉。
修法：把日志域样式移到 `log_panel.apply_log_view_style()` 里用 `view.setStyleSheet(...)`
直接设在控件上；同时从 `global_stylesheet()` 删掉那条死规则（并去掉因此不再使用的
`family` 参数）。这是「项目里一条长期失效的配置」，顺带修掉。
