# 桌面端操作指南（从导入到出 PDF）

面向**日常使用者**：不需要懂 Python、命令行或参数语法，照着点即可。

四个步骤固定顺序：**① 提取图片 → ② 检测文本框 → ③ 图片去底色 → ④ 生成 PDF**。
每一步完成并确认满意后再进入下一步；中途可以随时中断，之后「继续执行」只补没做完的部分。

> **本文截图取自真实操作**：以《龍譚精舍叢刻》扫描件（Harvard 藏本，63 页，
> 竖开本）为例，演示页为**第 4 页**（左右两栏都排满的规整正文）。
> 全部截图由 `tests/gui_shot.py --guide` 离屏渲染真实界面生成，界面改动后重跑即可刷新
> （见文末「维护」）。

---

## 0. 启动程序

```powershell
python desktop.py
# 或安装后直接运行 guji-desktop
```

数据目录默认在 `~/Documents/guji`，里面按任务号（`0001`、`0002`…）分目录存放
全部中间产物。程序不依赖数据库，删除任务即删除对应目录。

---

## 1. 导入 PDF

![任务列表页](screenshots/guide/s0-任务列表.png)

1. 点右上角 **「导入 PDF」**，选择要处理的扫描件；
2. 程序在后台计算文件指纹（按钮会短暂置灰），与已有任务比对：
   - **没有重复** → 直接创建任务；
   - **有重复** → 弹窗让你选「创建新任务」或「定位已有任务」。选定位会直接跳到已有任务，
     不会重复占用空间。

创建后会在后台逐页生成缩略图。列表中每个任务右侧有 4 个状态胶囊
（提取 / 检测 / 去底 / PDF），**灰色=未执行、蓝色=执行中、绿色=已完成、红色=失败**。

点 **「详情」** 进入操作页；点 **「删除」** 会连同该任务的全部中间产物一起清理。

---

## 2. 第一步：提取图片（extract）

把 PDF 每页渲染成图片，作为后续所有步骤的输入。

![提取结果](screenshots/guide/s1-提取-结果.png)

左侧预览区有两个标签页：

- **PDF 预览**：看原始文件，用来和提取结果对照；
- **提取结果**：看实际渲染出来的页面，下方缩略图条可**删页 / 插页**。

右侧控制列填参数：

![提取参数](screenshots/guide/s1-提取-参数.png)

| 参数 | 说明 | 建议 |
| --- | --- | --- |
| 缩放因子 zoom | 渲染倍率，越大越清晰、文件越大 | 扫描件一般 `1`；字迹细小时用 `2` |
| 输出格式 ext | `jpg` 体积小 / `png` 无损 | 黑白古籍用 `jpg` 足够 |
| 快速模式 quick | 优先直接取 PDF 内嵌图（更快、常更清晰） | **保持勾选**；遇到 jp2/jbig2 或内嵌图过小时程序会自动整页渲染 |
| 页码范围 pages | 留空=全部；示例 `1,2,5-7` | 先试跑几页确认效果时填 |

调好点 **「执行本子任务」**。状态胶囊转绿即完成，底部日志浮层会实时打印每页进度。

> **中断了？** 点 **「继续执行（跳过已完成）」**，只补没提取的页，已完成的不会重做。

---

## 3. 第二步：检测文本框（detect）

用 YOLO 找出每页的**左、右两个文本框**，结果只记坐标（不产生图片文件），
供第三步裁剪和去底色使用。

![检测默认结果](screenshots/guide/s2-检测-默认.png)

绿色框是左页文本区（画面左侧标「左框」），蓝色框是右页文本区（标「右框」），
框上方标注了坐标。右下角信息条同步显示当前页所有框的坐标。

> 进入本阶段**不会自动检测**（加载模型较慢），需要点右侧 **「检测本页」** 单独检测当前页，
> 或点 **「执行本子任务」** 批量检测全部页。

### 校正检测框

自动检测难免有偏差，预览区里可以直接改：

![选中框](screenshots/guide/s2-检测-选中框.png)

- **拖动**：在框内按住拖动，整体移动；
- **缩放**：点框选中后，拖四角的小方块；
- **删除**：选中后按 `Delete`；
- **手绘补充**：在**空白处**按住拖拽，画出新框。

![手绘补充框](screenshots/guide/s2-检测-手绘补充框.png)

上图在版心下方空白处手绘了第三个框（橙色），信息条末尾会追加一条
「左框(766,1973,1840,2171)（手动）」——**手动框用橙色区分，并带「（手动）」标记**。
它**不会被后续自动检测覆盖**，可以放心调整。

> 大多数情况下**不需要**在这一步手动改框：如果第三、四步的效果已经满意，直接跳过本阶段的
> 手动调整即可。检测算法与命令行 `detect` / `crop` / `cropremove` 完全同源，两个入口看到的框一致。
>
> 如果某一页**一个框都没检出**（如封面、扉页、空白页），那是**正常**的，不是报错——
> 这类页面本来就没有正文需要裁剪，后续步骤会按原样处理。

---

## 4. 第三步：图片去底色（rembg）

把页面底色去掉，得到干净的黑白（或灰度）正文，可选保留红色印章。

![去底色参数](screenshots/guide/s3-去底色-参数.png)

左侧预览默认显示**去底色结果**，顶部可切回**原图**对照。
**area / border 参数在这一步**（不在第二步），它们决定「取哪块区域」：

| 参数 | 说明 |
| --- | --- |
| area 区域模式 | `1 (左右分开)`：左右各出一张图，分别处理（**最常用**）<br>`2 (合并单图)`：左右合成一张，保留原页尺寸<br>`3 (整页合并)`：把左右框并成一个大框整页处理 |
| border 边距(mm) | 在框之外多留多少白边（类比 CSS margin）：`30`（四边）／`20,30`（上下,左右）／`20,30,25,35`（上,右,下,左）；留空=裁到框边界 |
| type 输出类型 | `1 (二值)` 纯黑白／`2 (1bit)` 体积最小／`3 (灰度)` 保留灰度过渡 |
| offset 阈值偏移 | 正数文字更粗更深，负数更细更淡；一般保持 `0` |
| 印章相关 | 勾 **保留印章 (seal)** 启用红色印章识别；**印章彩色 (sealcolor)** 在检出印章时输出彩色 PNG 保留红色 |

### 本阶段是「两段式」，务必按顺序点

![去底色结果](screenshots/guide/s3-去底色-结果.png)

1. 先点 **「生成预览」** —— 按当前参数算出结果供你检查；
2. 确认满意后，再点 **「提交本次任务」** —— 生成正式的去底色图片，供第四步使用。

改了 area / border / type / 印章任意一项后，程序会提示
**「● 去底参数已修改，请重新「生成预览」后再提交」**，此时「提交本次任务」变灰。
这是**有意设计**：避免你用着旧预览却提交了新参数，做出对不上的结果。

area=1 时左侧条目会按输出拆成 `N-r`（右页）和 `N-l`（左页），条目缩略图只显示所属的那半页。

## 5. 第四步：生成 PDF（print）

把上一步的去底色图片按你的顺序排好，加上标题、页码，合成最终 PDF。

![生成 PDF](screenshots/guide/s4-生成PDF-默认.png)

- 左侧是**图片瀑布流**：拖动排序、多选删除（或按 `Delete`）、
  **「插入图片」** 可引用外部文件。页序就是你看到的顺序，生成的 PDF 严格照此排列。

右侧填参数（分五组）：

![填写参数](screenshots/guide/s4-生成PDF-参数.png)

上图是《龍譚精舍叢刻》的实际填法：古籍名称填「龍譚精舍叢刻」后，
**PDF 文件名自动推导**为 `..._龍譚精舍叢刻_v.2[重制].pdf`（取源文件名 + `[重制]`）；
印刷古籍是竖开本，所以纸张方向选了**竖版**。

| 分组 | 关键参数 |
| --- | --- |
| 输出与纸张 | **古籍名称**（填了会自动推导 PDF 文件名）、PDF 文件名、纸张尺寸 A4/A3/A5/B5、纸张方向（横版/竖版） |
| 页边距(mm) | 通用边距 + 左/右页边距（左留空=同通用边距）。格式同 border：`20`／`20,30`／`20,30,25,35` |
| 标题排版 | 勾选**打印标题**后可设字号/颜色/位置/文字方向；**标题切换节点**用于「按页码切换书名」（如正文换篇） |
| 页码 | 勾选**打印页码**后可设起始页、页码基准（封面不计数时设 `0`）、位置、方向 |
| 过滤 | 跳过指定页等 |

> **竖开本古籍记得改「纸张方向」为竖版**——默认是横版，直接用会把竖长的页面
> 挤在横向纸张中间，两侧留大片空白。

点 **「执行本子任务」** 生成 PDF，输出在任务目录的 `stages/pdf/` 下。
顶部 **「打开目录」** 可直接跳到数据目录取文件。

## 6. 日志与排查

底部常驻一条**状态条**，显示最近一条输出：

![日志状态条](screenshots/guide/s5-日志状态条.png)

点它展开完整**日志浮层**（也可按右侧「展开」按钮）：

![执行日志浮层](screenshots/guide/s5-执行日志.png)

- 执行阶段时自动展开，实时滚动；
- **出错时状态圆点与摘要标红**，日志里能看到完整报错原因；
- 按 `Esc`、点击浮层外、或再点状态条即可收起。

### 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 第二步预览空白 / 没有框 | 本阶段不自动检测。点 **「检测本页」**（单页）或 **「执行本子任务」**（全部页） |
| 第二步某页完全没框 | **正常**：封面、扉页、空白页本就没有正文，检测返回「无框」不算失败 |
| 第三步「提交本次任务」是灰的 | 参数改过还没重新生成预览。先点 **「生成预览」** |
| 第三步结果和预览对不上 | 同上，改完参数必须重新生成预览再提交 |
| 生成 PDF 后两侧空白很大 | 竖开本古籍忘了把「纸张方向」改成**竖版**（默认横版） |
| 提取结果缺页 | 用 **「继续执行（跳过已完成）」** 补缺失页 |
| 某一步失败（胶囊变红） | 打开日志浮层看红字，常见是源文件被移动/权限不足；修正后重跑该步即可 |
| 手动改的框消失了 | 手动框（标「手动」）不会被自动结果覆盖；若整页被重新批量检测，请确认改的是当前页 |
| 左侧缩略图一排排发白、像没加载完 | 缩略图其实已就绪，是**检测框越界裁白**。多半是「页面尺寸」记录得不对（见「维护 → image_size 必须记阶段图尺寸」）；真实使用中若出现，重跑该步的 detect 后重开任务即可 |

## 维护

### 刷新截图

改完界面后刷新截图：

```bash
# 操作指南配图（写入 <输出目录>/guide/）
QT_QPA_PLATFORM=offscreen python tests/gui_shot.py --guide docs/guide/screenshots

# 界面总览配图（写入 <输出目录>/，供 gui-layout.md 引用）
QT_QPA_PLATFORM=offscreen python tests/gui_shot.py docs/guide/screenshots

# 功能回归（含指南一致性护栏）
QT_QPA_PLATFORM=offscreen python tests/gui_selftest.py
```

截图里的参数都是**真实控件状态**（选中框、手绘框、填好的表单），
不是示意图——改了控件名或布局，重跑一次就能发现脚本哪里失配。

### 演示数据来源（真实古籍优先）

`tests/gui_shot.py` 会按下面顺序找演示数据，**优先使用真实古籍**：

1. 环境变量 `GUJI_SHOT_PDF` 指向的 PDF；
2. `C:\Users\liuzu\Documents\test\` 下文件名含「龍譚精舍叢刻」的 PDF；
3. 该目录下任意 PDF。

找到后自动去同级 `guji_work/book/` 取已跑完的 `images/ detect/ rembg/` 产物，
把**真实页面图片 + 真实 YOLO 检测坐标**灌进演示任务——所以截图里是货真价实的
古籍版面，PDF 预览区显示的是真实源文件。

找不到真实 PDF 时自动回退到内置合成占位页，脚本在任何机器上都能跑
（输出会打印「演示数据回退为合成占位页」以提示）。

**演示页由 `gui_shot.py` 顶部的 `DEMO_PAGE` 常量决定，当前为第 4 页。**
（早先用第 3 页，但那一页正文只占右半栏、版面偏空，做演示不够典型；
第 4 页是左右两栏都排满的规整正文，更适合展示检测框与去底色效果。）
改这个常量会改变截图内容，**改完必须重跑 `gui_selftest.py --only gui_guide`**，
护栏会核对指南里的图片引用与阶段顺序。

#### ⚠️ `image_size` 必须记「阶段图尺寸」，不是缩略图尺寸

灌演示数据时有一个不报错、但界面直接「看起来没加载完」的坑：

`_page_thumb_for()` 用 `sx = 缩略图宽 / image_size 宽` 把**检测框坐标**
（阶段图坐标系）换算到缩略图上。如果 `image_size` 被写成了**缩略图**尺寸，
`sx` 就恒等于 `1`，于是 2400px 尺度的框被拿去裁 700px 的缩略图 → **越界裁出纯白**，
左侧缩略图列表就会一排排白块，和「图片还没加载出来」长得一模一样。

- 正确写法：`save_image_size(task_id, key, <阶段图宽>, <阶段图高>)`；
- 错误写法：传入 `image.width()`（那通常是缩放后的缩略图尺寸）。

`gui_selftest.py --only gui_guide` 里的「演示缩略图无全白（检测框与缩略图坐标自洽）」
会实际跑一遍合成并采样深色占比，命中就报
`001(深色仅 0%，疑越界裁白)`。

### 手动刷新一本新书的数据

若要用别的古籍重新出图，先按其目录跑完前三步，再指向它：

```bash
cd <该书工作目录>
python D:/workspace/gujitools/main.py extract -i ./book.pdf
python D:/workspace/gujitools/main.py detect  -i ./book/images --save
python D:/workspace/gujitools/main.py rembg   -i ./book/images --seal --sealcolor

# 回到仓库，指定这本书出图
GUJI_SHOT_PDF=<该书工作目录>/book.pdf \
  QT_QPA_PLATFORM=offscreen python tests/gui_shot.py --guide docs/guide/screenshots
```

> 中间产物目录名必须是 `book/`（含 `images/ detect/ rembg/`），
> 脚本按 `_sibling_work_dir()` 的约定去找。
