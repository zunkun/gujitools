# 桌面端布局文档（与 desktop/ 当前实现对齐）

## 1. 主窗口

- 尺寸 1400×900，标题「guji 古籍处理平台」；QStackedWidget 切换
  任务列表页 / 任务详情页。

## 2. 任务列表页

```
┌──────────────────────────────────────────────┐
│ 卡片：任务管理                     [导入PDF] │
├──────────────────────────────────────────────┤
│ 表格：序号|任务名|源文件|创建时间|阶段摘要|操作 │
├──────────────────────────────────────────────┤
│ 共 N 个任务    数据目录：…                    │
└──────────────────────────────────────────────┘
```

## 3. 任务详情页

```
┌──────────────────────────────────────────────────────┐
│ [←] 任务详情  <源文件名>                    [打开目录] │
├──────────────────────────────────────────────────────┤
│ 步骤条：[1 提取] [2 检测] [3 去底色] [4 打印]          │
├──────────────────────────────────────┬───────────────┤
│                                      │ 历史执行配置 ▾ │
│           预览区（随阶段切换）         │ ── 阶段参数 ── │
│                                      │ 阶段状态/进度  │
│                                      │ [执行][续跑]   │
│                                      │ [中断]        │
├──────────────────────────────────────┴───────────────┤
│ 执行日志（只读，140px）                               │
└──────────────────────────────────────────────────────┘
```

- 预览区占满剩余宽度；控制列限宽 260–300px。
- 预览区按阶段：
  - extract：QTabWidget [PDF 预览 | 提取结果]；
  - detect：图片查看器（缩略图条 + 大图，框叠加/手柄）；
  - rembg：输出条目列表 + 顶部[去底色结果|原图]切换 + 单视图；
  - print：图片瀑布流（工具条：插入/删除/拖动排序）。

## 4. 组件尺寸约定

- 页面缩略图条：条目图标 96×128，列表宽 132px；
- 页缩略图磁盘规格：256px 长边 JPEG（`0001.jpg`…）；
- 控制列：min 260 / max 300；
- 日志区：固定高 140。
